Performing Readback
To Perform Readback
  1. Select Operations > Readback, or right-click on the device icon and select Readback.
  2. In the Save Readback File dialog box, select a directory and file name.
The programmed contents of the selected device are read back and a JEDEC file is created for CPLDs, an MCS file for PROMs.
Note The JEDEC or MCS file can be used to configure other devices. A device that was read protected cannot be read back.
