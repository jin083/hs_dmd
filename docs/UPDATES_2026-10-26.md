# 2026-10-26: D201 연결 복구와 USB burst 경계 수정

기존 bitstream의 JTAG 구성, USB 연결, DDR2 calibration 및 10장 업로드는 확인했습니다. 숫자 1 표시 명령은 FPGA에서 완료됐지만 사용자는 고정된 깨진 영상과 좌표 이상을 확인했습니다. **광학 검증은 실패이며 수정 후보 bitstream의 재검증이 필요합니다.** 사용자가 이후 DMD 전원을 내렸으므로, 이후 작업은 장비 접근 없이 로컬 ISE 시뮬레이션과 빌드로 진행합니다.

## 실기에서 확인한 단계

1. 패턴용 D4100 USB는 PC USB 포트를 바꾼 뒤 인식됐습니다. Xilinx JTAG 케이블과 별개입니다.
2. 최초 ABI 읽기 `0xDEAD`는 현재 FPGA에 D201 레지스터가 없음을 나타냈습니다. Xilinx 케이블 물리 재연결 후 iMPACT에서 LX50/LX30 체인을 확인했습니다.
3. 체인 위치 1의 LX50에 2026-10-23 JTAG 파일을 기록했습니다. SHA-256은 `d6e4b40456b90445aa84cf1a2360d2cdee895f4bbc3964dd9364387f5a534a39`입니다. DONE=1, startup 완료=1, CRC/ID 오류=0을 확인했습니다. LX30/PROM은 재프로그램하지 않았습니다.
4. 구성 직후 32/64-bit TI DLL에서 기존/신규 레지스터 모두 `0x0000`이었습니다. 패턴 USB 재연결은 효과가 없었고, **SW2를 눌렀다 놓은 뒤** ABI `0xD201`, 상태 `0x0101`, Calibrated=true로 복구됐습니다. 정확히 어느 내부 초기화 단계가 누락됐는지는 계측하지 않았습니다. SW2는 APPSFPGA/DLPC410/DMD 로직 리셋입니다. [TI 보드 안내 §2.2.4.2](https://www.ti.com/lit/ug/dlpu040c/dlpu040c.pdf)
5. Python API가 생성한 절대 패턴 경로에 PowerShell이 plan 폴더를 다시 붙이면서 `GetFullPath` 오류가 발생했습니다. 절대 경로는 그대로 처리하고 상대 경로만 plan 폴더와 결합하도록 수정했습니다.
6. 수정 후 `dmd-test upload`에서 UploadedPatterns=10, Loaded=true, Error=false가 확인됐습니다. `show --number 1`은 Done=true, CompletedLoops=1, Running=false로 완료됐습니다. **DDR2 readback/해시 검증을 수행한 결과는 아닙니다.**
7. 사용자는 영상이 깨졌고 고정된 좌표 변환 이상처럼 보인다고 보고했습니다. 시퀀스·고속·무한 반복은 수행하지 않았습니다. 이후 전원 차단 지시에 따라 USB/JTAG 접근을 중단했습니다.

원본 명령 결과와 사용자 관찰은 [실기 기록](../artifacts/dmd-program-20261026/programming_result.json)에 분리해 보관합니다. CLI가 기록한 `optical_verdict: not_evaluated`는 자동 판정 범위이고, 별도 사용자 관찰은 `failed`입니다.

## 발견한 RTL 오류와 수정

[TI DLPU045A, 표 2의 주석](https://www.ti.com/lit/ug/dlpu045a/dlpu045a.pdf)은 FIFO burst의 마지막 워드를 저장하지 않도록 명시합니다. 기존 TI USB→DMD 경로는 이 조건을 구현합니다. 반면 추가한 DDR2 경로는 모든 asserted-WEN 샘플을 payload로 간주해 마지막 워드까지 FIFO에 저장했습니다. 패킷 경계를 지날 때 픽셀 위치가 누적해서 밀릴 수 있으며, 프레임 개수만 세는 완료 플래그로는 검출되지 않습니다.

`USB_IO.vhd`의 DDR 쓰기 유효 신호에 TI 경로와 같은 연속 strobe 조건을 적용했습니다. payload와 지연된 데이터의 정렬을 유지하면서 burst 마지막 워드만 제외합니다. 행 번호에 따른 임의 데이터 삭제는 복원하지 않았습니다. DDR2 주소 배치, MIG/IP, TI 출력 IO, DMD 행/채널 매핑은 수정하지 않았습니다.

이전 USB 테스트는 burst의 모든 워드를 유효 데이터로 모델링하여 이 오류를 놓쳤습니다. 테스트에 payload와 구별되는 마지막 워드, 연속 512-byte 패킷, 단일 워드 및 작은 burst를 추가했습니다. **수정 전 첫 데이터 비교에서 실패했고, 수정 후 데이터·개수·레지스터 읽기/쓰기 검사를 통과했습니다.** 별도 메모리 재생 회귀 검사도 통과했습니다. 물리 GPIF 파형을 캡처한 것은 아니므로 수정 뒤 실제 영상 확인은 여전히 필요합니다.

## 패키지와 검증

- `dlpc410`: 절대/상대 패턴 경로 수정, 실제 읽힌 ABI와 SW2 조치를 포함하는 오류 안내. Windows PowerShell 경로 회귀 검사 포함 15개 테스트 통과.
- `DMD-FPGA-Test`: CLI 테스트 5개 통과. CLI 예시는 editable 설치 후 `dmd-test ...`를 사용합니다. 새 프로젝트 가상환경은 만들지 않습니다.
- FPGA: 실제 Xilinx FIFO/PLL 모델을 사용하는 `usb_memory_tb`, MIG user-port 모델을 사용하는 `memory_playback_tb` 통과. 수정 전 실패 로그도 보존합니다.

## 새 후보 산출물과 다음 실기 순서

설치된 ISE 14.7과 저장소의 IP를 이용하여 외부 다운로드 없이 전체 합성·배치·배선·TRCE·BitGen을 완료했습니다. 기존 산출물을 보존하고 [새 후보 폴더](../artifacts/dmd-20261026/)에 JTAG 및 USB/SelectMAP용 BIT/BIN을 저장했습니다. **이 후보를 장비에 기록하지 않았습니다.**

- 합성 오류 0개, 최종 setup/hold 오류 0개, timing score 0, BitGen DRC 오류 0개.
- 200MHz 시스템 setup slack 0.044ns, 150MHz 메모리 setup slack 0.270ns.
- 빌드 입력 79개·시뮬레이션 입력 13개의 해시가 현재 소스와 일치합니다. 기존 bitstream 7개는 원본 커밋과 동일합니다.
- [JTAG bitstream](../artifacts/dmd-20261026/appsfpga_repaired_jtag.bit) SHA-256: `48b42b1f260687d8cb05db0119f1b42282dc543090c3b60dde2baede5d7a120b`.
- 합성 경고 1,987개, PAR 경고 52개, BitGen DRC 경고 26개는 남아 있습니다. DRC는 미사용 신호 24개와 기존 active-net pulldown 2개입니다. 기존 USB 입력 OFFSET에 VALID duration이 없어 입력 hold 검사가 포함되지 않는 범위도 유지됩니다. 적용된 제약 통과를 모든 외부 인터페이스의 전기적 검증으로 해석하지 않습니다.

전체 수치·검증 범위는 [validation.json](../artifacts/dmd-20261026/validation.json), 파일 해시는 [artifact_hashes.json](../artifacts/dmd-20261026/artifact_hashes.json), 원본 보고서는 [reports/](../artifacts/dmd-20261026/reports/)에 보관합니다.

다음 전원 인가 후 LX50에 새 JTAG 파일 구성 → SW2 → `dmd-test status`에서 D201/Calibrated 확인 → 숫자 10장 재업로드 → 숫자 1 단일 표시와 L 마커 확인 순서로 검증합니다. 현재 고정 영상의 정확한 깨짐 원인이 모두 해소됐는지는 그 결과로 판정합니다. 그 전에는 최소 타이밍/무한 반복의 실기 검증 완료를 주장하지 않습니다.

## 온도

iMPACT의 구성 전후 자동 센서 조회에서 두 칩 모두 -273°C/0V가 나왔습니다. 유효하지 않은 값이며 실제 접합온도는 미측정입니다. 내장 센서 이용 가능 여부는 [ChipScope 안내](CHIPSCOPE_TEMPERATURE.md)를 따라 별도로 확인합니다. 발열 증가 원인이나 안전한 연속 운전 여부는 이번 USB 수정으로 판정할 수 없습니다.
